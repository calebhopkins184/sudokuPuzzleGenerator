Switching

Ubuntu alternatives to Windows and Mac apps

Most everyday Windows and Mac software has a capable Ubuntu alternative, and many popular apps (Chrome, Firefox, Spotify, Zoom, Slack, VS Code, Steam) run natively. For the rest, web versions, Wine-based compatibility tools, or a virtual machine usually fill the gap.

Updated November 2, 2026 · By the UbuntuApps team

Apps that already run natively on Ubuntu

Before looking for alternatives, check whether you even need one. These widely used apps have official Linux versions:

  • Google Chrome, Firefox, Microsoft Edge, Brave, Vivaldi
  • Spotify, Zoom, Slack, Discord, Telegram, Signal
  • Visual Studio Code, JetBrains IDEs, Android Studio
  • Steam, Blender, OBS Studio, DaVinci Resolve
  • Obsidian, Bitwarden, Dropbox

When there's no alternative: compatibility options

Wine and Bottles

Wine is a compatibility layer that runs many Windows programs directly on Linux, without a Windows license. Bottles (available on Flathub) is a friendly front end that creates separate, isolated environments for each program and installs common dependencies for you. Older and simpler programs tend to work best; recent professional software with heavy DRM often doesn't. The WineHQ AppDB has user reports for specific programs.

Steam Proton for games

Proton is Valve's Wine-based compatibility tool built into Steam. Enable it under Steam > Settings > Compatibility. Many Windows games run with little or no tweaking, but titles with certain anti-cheat systems may not be allowed on Linux. ProtonDB collects compatibility reports. For games outside Steam, try Lutris or Heroic Games Launcher.

Virtual machines

If you need an app that won't run any other way, a virtual machine runs a full copy of Windows inside Ubuntu. GNOME Boxes is the simplest option; VirtualBox and virt-manager (KVM) offer more control. You'll need a valid Windows license, and graphics-heavy apps and games perform poorly in VMs.

Dual booting

For demanding software like the full Adobe suite or games that block Linux, keeping Windows on a separate partition and choosing at startup is the most reliable fallback. Back up first, and expect to disable Fast Startup in Windows to avoid disk access problems.

Tips for a smooth switch

  1. List the apps you use every week and check each one against this page before you switch.
  2. Try alternatives on your current system first. LibreOffice, GIMP, Inkscape, Kdenlive, Thunderbird, and VLC all run on Windows and macOS too.
  3. Use a live USB to test Ubuntu on your hardware without installing.
  4. Move to cross-platform file formats where possible, such as PDF, Markdown, and open document formats.
  5. Keep cloud copies of important files during the transition.

Frequently asked questions

Can LibreOffice open Microsoft Word and Excel files?

Yes. LibreOffice opens and saves .docx, .xlsx, and .pptx files. Simple documents convert cleanly; complex layouts, macros, and some Excel features may need adjustment. OnlyOffice often matches Office formatting more closely.

Is there a Linux version of Microsoft Teams?

Microsoft retired its native Teams app for Linux and recommends using Teams in a web browser, which can be installed as a progressive web app in Chrome or Edge.

Will my Windows games work on Ubuntu?

Many will through Steam's Proton compatibility layer. Games with certain anti-cheat systems may not. Check ProtonDB for reports on specific games before you switch.
