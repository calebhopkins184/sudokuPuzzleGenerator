The best apps for Ubuntu, by category

The best Ubuntu apps are mostly free, open source, and available straight from App Center or the Ubuntu archive. Below are dependable choices in each category, how to install them, and when an alternative might suit you better.

Updated November 2, 2026 · By the UbuntuApps team

Package names below are for the Ubuntu archive (apt) or the Snap Store (snap) unless noted. Availability can change between releases; if a command fails, search App Center for the app name.

Web browsers

  • Firefox comes preinstalled as a snap, with built-in tracking protection and sync.
  • Google Chrome is available as an official .deb from Google's website. Installing it adds Google's repository, so it updates with your system.
  • Chromium, the open-source base of Chrome, is available as a snap: sudo snap install chromium.
  • Brave and Vivaldi publish official Linux packages and repositories on their websites.

Office and productivity

  • LibreOffice is the standard free office suite, with Writer, Calc, Impress, and more. It's included in Ubuntu's extended install, or run sudo apt install libreoffice.
  • OnlyOffice Desktop Editors has an interface close to Microsoft Office and strong .docx, .xlsx, and .pptx compatibility. Available as a snap, Flatpak, or .deb.
  • Microsoft 365 on the web works in any modern browser if you need exact Office compatibility.

Email and calendar

  • Thunderbird, preinstalled on standard Ubuntu desktops, handles email, calendars, contacts, and RSS.
  • Evolution (sudo apt install evolution) integrates well with GNOME and supports Microsoft Exchange through an add-on.
  • Geary is a lightweight, simple mail client.

Media players and music

  • VLC plays almost any audio or video format: sudo apt install vlc or sudo snap install vlc.
  • mpv is a minimalist, high-quality video player; Celluloid is a friendly GNOME front end for it.
  • Rhythmbox manages a local music library; Lollypop is a more modern-looking alternative.
  • Spotify offers an official snap: sudo snap install spotify.

Video and audio production

  • Kdenlive: a full-featured, non-linear video editor. Available via apt, Flatpak, or AppImage; the Flatpak or AppImage is usually newer.
  • Shotcut and OpenShot: simpler editors for quick projects.
  • DaVinci Resolve: a professional editor with an official Linux version. Installation is more involved, and the free edition has codec limitations on Linux, so check Blackmagic's system requirements first.
  • OBS Studio: screen recording and live streaming. The OBS project maintains an official PPA and a Flatpak.
  • Audacity: audio recording and editing. Ardour: a full digital audio workstation.

Development tools

  • Visual Studio Code: sudo snap install code --classic, or Microsoft's .deb. VSCodium is a build without Microsoft telemetry and branding.
  • JetBrains Toolbox installs and updates IntelliJ IDEA, PyCharm, and other JetBrains IDEs. Several IDEs are also available as snaps.
  • Git: sudo apt install git.
  • Docker Engine: follow Docker's official instructions to add its apt repository; Ubuntu also packages docker.io.
  • GNOME Builder and Kate: capable lighter-weight editors.

Notes, knowledge, and passwords

  • Obsidian: Markdown notes stored as local files. Official AppImage, .deb, snap, and Flatpak.
  • Joplin: open-source notes with end-to-end encrypted sync.
  • KeePassXC: an offline password manager (sudo apt install keepassxc).
  • Bitwarden: a cloud-synced, open-source password manager with a desktop app (snap or Flatpak) and browser extensions.

Communication

  • Signal Desktop: official apt repository from Signal, plus a community snap.
  • Telegram, Discord, Slack, and Zoom all offer Linux desktop apps (snap, .deb, or Flatpak).
  • Element: a client for the Matrix open messaging network.

System utilities

  • Timeshift: system snapshots you can roll back to (sudo apt install timeshift).
  • GNOME Disks (preinstalled) and GParted: disk and partition management.
  • Flameshot: annotated screenshots (sudo apt install flameshot).
  • Syncthing: peer-to-peer file sync between your devices, no cloud required.
  • GNOME Boxes and VirtualBox: run other operating systems in virtual machines.
  • htop and btop: friendly terminal process monitors.

Gaming

  • Steam: install from Valve's official .deb or via App Center. Enable Steam Play (Proton) in settings to run many Windows-only games.
  • Lutris: manages games from multiple sources, including GOG and emulators.
  • Heroic Games Launcher: an open-source launcher for Epic, GOG, and Amazon game libraries.

Check a game's compatibility on ProtonDB before buying, especially multiplayer titles with anti-cheat, which may block Linux.

Frequently asked questions

Are apps in App Center safe?

Apps from the Ubuntu archive are maintained by Ubuntu and its community, and snaps from verified publishers come directly from the developer. Snaps from unknown publishers deserve more caution: check the publisher name, the project's website, and the app's reviews before installing.

Why does the same app appear more than once in App Center?

An app may be available as both a snap and a .deb package from the Ubuntu archive. The versions can differ. Check the source shown on the app's page and pick the one you prefer.

Do Microsoft Office and Adobe apps run on Ubuntu?

Not natively. Microsoft 365 works in a web browser, and LibreOffice or OnlyOffice handle most Office files. Adobe Creative Cloud apps don't have Linux versions; see our alternatives guide for substitutes.
