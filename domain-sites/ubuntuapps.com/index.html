Five commands every Ubuntu user should know

# Refresh package lists and install updates
sudo apt update && sudo apt upgrade

# Install an app from the Ubuntu archive
sudo apt install vlc

# Install an app as a snap
sudo snap install vlc

# See which Ubuntu release you're running
lsb_release -a

# Remove an app and clean up unused dependencies
sudo apt remove vlc && sudo apt autoremove

Prefer clicking? App Center, Ubuntu's built-in store, handles search, install, updates, and removal for snaps and many apt packages.

Where Ubuntu apps come from

Ubuntu apps come from a few trusted sources, and knowing which one you're using explains most of the confusion new users run into:

  • The Ubuntu archive (installed with apt): tens of thousands of packages built and maintained by Ubuntu and Debian developers. Very stable, though versions on an LTS release don't change much over its lifetime.
  • The Snap Store (snap and App Center): apps packaged by Canonical, community members, or the app developers themselves, updated automatically.
  • Flathub (Flatpak): a cross-distribution app store, popular with GNOME and KDE app developers. Not enabled on Ubuntu by default.
  • Developer websites: official .deb packages, repositories, or AppImages for apps such as Chrome, VS Code, Steam, and Obsidian.

Our rule of thumb: install from the official source closest to the developer, avoid random download sites, and stick to one format per app so updates stay predictable. The packaging guide explains the tradeoffs in detail, and the alternatives guide helps if you're coming from Windows or macOS.

Frequently asked questions

What is the easiest way to install apps on Ubuntu?

Open App Center, search for the app, and click Install. For apps not listed there, use sudo apt install in a terminal or download the developer's official .deb package.

Should I use snap or apt?

Use apt for system tools and libraries and for most traditional desktop apps in the Ubuntu archive. Snaps are handy for apps that update quickly, such as browsers and developer tools, because the publisher ships updates directly. Both are maintained and safe when the source is official.

Does Ubuntu support Flatpak?

Yes, but it isn't set up by default. Install the flatpak package and add the Flathub repository, then you can install Flatpak apps from the terminal or from GNOME Software with the Flatpak plugin.

Can I run Windows apps on Ubuntu?

Many Windows programs run through Wine or a Wine front end like Bottles, and Steam's Proton runs a large number of Windows games. Some apps, especially those with anti-cheat or deep system integration, don't work, so check native or web alternatives first.

Which Ubuntu version should I install?

Most people should install the latest LTS (long-term support) release, which gets five years of standard security updates. Interim releases get only nine months of support and are best for people who want the newest features.

Is Ubuntu software free?

Ubuntu itself and the vast majority of apps in its repositories are free and open source. Some apps available for Ubuntu, such as certain commercial tools or games, are proprietary or paid.
