About UbuntuApps

UbuntuApps is an independent site that helps people get productive on Ubuntu: which apps to install, how to install them, and how to keep a system healthy.

What we cover

  • The best apps for Ubuntu, by category
  • How software installation works: apt, snap, Flatpak, .deb, and AppImage
  • What to do after installing Ubuntu
  • Ubuntu alternatives to Windows and Mac apps
  • Ubuntu LTS releases and upgrades

How we write guides

  • Commands and package names are checked against current Ubuntu LTS releases. When something differs between releases, we say so.
  • We prefer official sources: Ubuntu documentation, Canonical's release and lifecycle pages, and each app's own website.
  • We recommend installing software from official repositories and verified publishers, not random download sites.

Independence

Ubuntu is a registered trademark of Canonical Ltd. UbuntuApps is not affiliated with, endorsed by, or sponsored by Canonical. We don't sell software, and app developers don't pay to be listed.

Found an error?

Linux moves fast and commands change. If a step didn't work for you, tell us which page, your Ubuntu version, and the error message.
