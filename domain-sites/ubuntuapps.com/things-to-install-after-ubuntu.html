Checklist

Things to do after installing Ubuntu: a practical checklist

After a fresh Ubuntu install, update the system, install any proprietary drivers your hardware needs, add media codecs, set up backups, and then install the handful of apps you'll actually use. The whole checklist takes under an hour.

Updated November 2, 2026 · By the UbuntuApps team

1. Install all updates

Installation media is often weeks or months old, so start by bringing everything current. Open Software Updater, or run:

sudo apt update && sudo apt full-upgrade
sudo snap refresh

Restart if the updater asks, especially after kernel updates.

2. Install hardware drivers

Ubuntu includes open-source drivers for most hardware. Some devices, notably NVIDIA graphics cards and certain Wi-Fi chips, work better with proprietary drivers.

  • Open Software & Updates and go to the Additional Drivers tab, then choose the recommended (tested) driver.
  • Or let Ubuntu pick for you from the terminal:
ubuntu-drivers list
sudo ubuntu-drivers install

Reboot after installing a graphics driver. If your system uses Secure Boot, you may be asked to set a password and enroll a key (MOK) on the next boot.

3. Add media codecs and fonts

For MP3, H.264, and other patent-encumbered formats, plus Microsoft core fonts, install the restricted extras package. You may have already done this by ticking "Install third-party software" during installation.

sudo apt install ubuntu-restricted-extras

During installation, you'll be asked to accept the Microsoft fonts license. Use the Tab key to select OK and press Enter.

4. Set up backups and snapshots

Two complementary tools cover most needs:

  • Timeshift takes snapshots of system files so you can roll back a bad update. It doesn't back up personal files by default.
    sudo apt install timeshift
  • Déjà Dup (shown as Backups) backs up your home folder to an external drive, network share, or cloud storage, with encryption and scheduling.
    sudo apt install deja-dup

Test a restore once, so you know it works before you need it.

5. Turn on the firewall

Ubuntu ships with ufw (Uncomplicated Firewall) installed but disabled. On a laptop that joins public networks, enabling it is a sensible default:

sudo ufw enable
sudo ufw status verbose

The default policy blocks incoming connections and allows outgoing ones. If you run a service like SSH, allow it explicitly with sudo ufw allow ssh. Prefer a graphical tool? Install gufw.

6. Consider Ubuntu Pro

Ubuntu Pro is free for personal use on a small number of machines. Attaching it adds Expanded Security Maintenance for the universe repository and Livepatch, which applies critical kernel fixes without rebooting. Open Software & Updates > Ubuntu Pro, or follow the instructions at ubuntu.com/pro.

7. Set up Flatpak (optional)

If you want access to Flathub's catalog in addition to App Center, enable Flatpak:

sudo apt install flatpak gnome-software-plugin-flatpak
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Restart your session afterward. See our packaging guide for when to use Flatpak versus snaps.

8. Install the essential apps

A minimal Ubuntu install includes a browser, file manager, and a few utilities. Most people add some of these:

9. Personalize the desktop

  • Settings > Ubuntu Desktop: change dock position, size, and auto-hide behavior.
  • Settings > Appearance: switch between light and dark styles and pick an accent color.
  • Settings > Displays > Night Light: warm the screen color in the evening.
  • GNOME Tweaks: adjust fonts, title-bar buttons, and startup apps.
  • Extension Manager: browse and install GNOME extensions, such as clipboard managers or system monitors, without visiting a website.

10. Tidy up

sudo apt autoremove
sudo apt clean

These remove packages that are no longer needed and clear downloaded package files. Finally, note which release you installed (lsb_release -a) and when its support ends. Our LTS releases guide has the timeline.

Frequently asked questions

Do I need antivirus on Ubuntu?

Most desktop users don't run traditional antivirus on Ubuntu. Keeping the system updated, installing software only from trusted sources, and using a firewall on untrusted networks matter more. ClamAV is available if you need to scan files you share with Windows users.

Should I install the NVIDIA proprietary driver?

For gaming, CUDA, and best performance on NVIDIA cards, usually yes. Use the Additional Drivers tool or sudo ubuntu-drivers install to get a tested version from Ubuntu's repositories rather than downloading one from NVIDIA's website.

Is it safe to enable Ubuntu Pro?

Yes. Ubuntu Pro is Canonical's official subscription, free for personal use on a small number of machines. It adds extended security maintenance for more packages and optional Livepatch kernel updates.
