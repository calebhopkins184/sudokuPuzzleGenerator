Excel vs Google Sheets: what is different?

Most everyday formulas work identically in both apps. The differences show up in a few places:

FeatureMicrosoft ExcelGoogle Sheets
XLOOKUP, FILTER, UNIQUE, SORTMicrosoft 365, Excel 2021 and later, and Excel for the webAvailable
Pivot table refreshManual: click Refresh when source data changesUpdates automatically
Structured table references (Table1[Amount])Yes, with Insert > TableYes in newer Google Sheets tables (Format > Convert to table); open ranges like A2:A are also common
CollaborationReal-time co-authoring with files in OneDrive or SharePointReal-time by default
Unique functionsPower Query, Power PivotQUERY, IMPORTRANGE, GOOGLEFINANCE

Frequently asked questions

Is XLOOKUP better than VLOOKUP?

For most new work, yes. XLOOKUP defaults to exact match, can look left or right, does not break when you insert columns, and has a built-in value for missing results. Use VLOOKUP only when you need compatibility with Excel 2019 or older.

Do Excel formulas work in Google Sheets?

Most do. Common functions like SUM, IF, SUMIFS, COUNTIFS, VLOOKUP, XLOOKUP, INDEX, and MATCH use the same syntax. Some features differ, such as Excel's structured table references and Google Sheets' QUERY function.

How do I make a cell reference absolute?

Add dollar signs: $A$1 locks both the column and row, $A1 locks only the column, and A$1 locks only the row. In Excel for Windows and Google Sheets you can press F4 while editing a reference to cycle through the options.

Why does my pivot table not show new data?

In Excel, pivot tables do not update automatically. Click Refresh on the PivotTable Analyze tab, and make sure the source range includes the new rows — formatting the data as a table with Ctrl+T makes the range expand automatically. Google Sheets pivot tables update on their own.

How do I highlight an entire row based on one cell?

Select the whole data range, create a conditional formatting rule using a custom formula, and lock the column but not the row, such as =$F2="Overdue". The rule then checks column F for each row.
