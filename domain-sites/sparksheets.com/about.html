About SparkSheets

SparkSheets is an independent tutorial site for people who use spreadsheets to get real work done — office reports, small business tracking, class gradebooks, and household budgets.

How we write tutorials

  • Formulas first. Every tutorial includes formulas you can copy, with each argument explained.
  • Both apps. Microsoft Excel and Google Sheets are similar but not identical. When a step differs, we show both versions and note which Excel versions support newer functions like XLOOKUP and FILTER.
  • Realistic examples. Sample data looks like the tables you actually work with, not abstract A1:B2 puzzles.
  • Explain the why. Understanding relative and absolute references, or why VLOOKUP defaults to approximate match, prevents errors later.

Official documentation

For complete function references, Microsoft's Excel help center and Google's Sheets function list are the authoritative sources. Menus occasionally move between app updates; if a menu path in one of our tutorials no longer matches, please tell us.
