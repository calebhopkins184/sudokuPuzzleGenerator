Conditional formatting in Excel and Google Sheets, with formula examples

Updated November 2, 2026 · By the SparkSheets team

Conditional formatting automatically changes a cell's color, font, or icon based on its value or a formula. Use it to highlight overdue tasks, flag numbers over budget, find duplicates, or turn a column of numbers into a heat map. Built-in rules handle simple cases; custom formulas handle everything else.

Where to find it

  • Excel: select your cells, then Home > Conditional Formatting. Use Manage Rules to edit, reorder, or delete rules.
  • Google Sheets: select your cells, then Format > Conditional formatting. The sidebar has Single color and Color scale tabs.

Custom formula rules: the real power

A custom formula rule applies formatting wherever the formula returns TRUE.

  • Excel: Conditional Formatting > New Rule > Use a formula to determine which cells to format.
  • Google Sheets: Format cells if... > Custom formula is.

The key is writing the formula for the top-left cell of your selection. The app then adjusts it for every other cell, following the same relative and absolute reference rules as copying a formula.

Highlight an entire row based on one column

Task list in A2:F100, with status in column F. To color every row where status is "Overdue":

  1. Select A2:F100 (start at row 2, not the header).
  2. Add a custom formula rule:
=$F2="Overdue"

The $ locks column F, so every cell in the row checks the status column. The row number has no $, so each row checks its own status.

Flag past-due items that are not done

Due date in column D, status in column E:

=AND($D2<TODAY(), $E2<>"Done", $D2<>"")

The last condition skips rows with no due date, since a blank cell counts as zero, which is earlier than today.

Due within the next 7 days

=AND($D2>=TODAY(), $D2<=TODAY()+7)

Highlight duplicates in Google Sheets

Select A2:A500 and use:

=COUNTIF($A$2:$A$500, A2)>1

Every value that appears more than once is highlighted. To highlight only the second and later occurrences, use a range that grows as it goes down:

=COUNTIF($A$2:A2, A2)>1

Banded rows

Excel tables (Ctrl+T) and Google Sheets' Format > Alternating colors create banding instantly. For a formula approach in either app:

=MOD(ROW(), 2)=0

Over budget

Budget in column B, actual in column C. Select C2:C20:

=$C2>$B2

The budget spreadsheet tutorial uses this rule plus a color scale for spending percentages.

Weekends in a date row

For dates in row 1 of a calendar or schedule (B1:AF1), selecting B1:AF20:

=WEEKDAY(B$1, 2)>5

WEEKDAY(..., 2) numbers Monday as 1 through Sunday as 7, so values above 5 are Saturday and Sunday. Here the row is locked with $ instead of the column.

Top 3 values

=C2>=LARGE($C$2:$C$50, 3)

Color scales and data bars

Color scales shade cells on a gradient from lowest to highest. They are ideal for spotting patterns in grids — sales by month and region, or test scores by question.

  • Pick a scale where the colors have a clear meaning, such as white-to-green for "more is better."
  • Avoid red-green scales if colorblind readers will use the sheet; blue-orange or a single-hue scale is easier for many people to read.
  • Set fixed minimum and maximum values (Excel: Manage Rules > Edit Rule; Sheets: Minpoint and Maxpoint) if you want colors to mean the same thing month to month.

In Excel, Data Bars draw a bar inside each cell proportional to its value. In Google Sheets, a similar effect is possible with the SPARKLINE function in a neighboring cell:

=SPARKLINE(C2, {"charttype","bar"; "max", MAX($C$2:$C$50)})

Rule order and conflicts

When several rules apply to the same cell:

  • Excel applies rules in the order shown in Manage Rules. If two rules set the same property, such as fill color, the higher rule wins. Check Stop If True to prevent lower rules from applying.
  • Google Sheets applies the first matching rule in the sidebar list and ignores the rest for that cell. Drag rules to reorder them.

Troubleshooting

SymptomFix
Rule highlights the wrong rowsYour formula refers to a different row than the first row of the selection; rewrite it for the top-left cell
Whole column highlights or nothing doesCheck the $ signs; you probably locked the row or forgot to lock the column
Text comparisons failLook for extra spaces; use TRIM() in the formula
Numbers stored as text do not compareConvert them to real numbers first
Rule references another sheet in Google SheetsUse INDIRECT("Sheet2!A1"), since direct cross-sheet references are not allowed there
Sheet becomes slowLimit ranges to the rows you use instead of entire columns, and reduce volatile functions like TODAY() in large rule sets

Keep it readable

Conditional formatting works best when it draws attention to exceptions. Use one or two highlight colors with a clear meaning, add a short legend, and resist formatting everything. If every cell is colored, nothing stands out.
