How to make a budget spreadsheet in Excel or Google Sheets

Updated November 2, 2026 · By the SparkSheets team

A good budget spreadsheet has three parts: a list of categories with monthly targets, a transactions log where you record every income and expense, and a summary that totals actual spending by category for the month using SUMIFS. Add a dropdown for categories and conditional formatting for overspending, and you have a reusable budget in under an hour.

The structure: three tabs

TabPurposeColumns
CategoriesYour list of categories and monthly budget for eachCategory, Type, Monthly budget
TransactionsOne row per income or expenseDate, Description, Category, Amount
SummaryBudget vs actual for a chosen monthCategory, Budget, Actual, Remaining, % used

Keeping raw data (transactions) separate from reporting (summary) means you never have to rebuild formulas — you just add rows.

Step 1: Build the Categories tab

In a tab named Categories, enter headers in row 1 and your categories below:

ABC
1CategoryTypeMonthly budget
2PaycheckIncome4,200
3RentExpense1,350
4GroceriesExpense450
5UtilitiesExpense160
6TransportationExpense220
7Dining outExpense250
8FunExpense200
9SavingsExpense800

Treat savings as a "spending" category so it gets a target like any other bill. The numbers above are just placeholders; use your own.

Step 2: Build the Transactions tab

Create a tab named Transactions with headers Date, Description, Category, and Amount in A1:D1. Enter every amount as a positive number; the category's type tells the summary whether it is income or an expense.

In Excel, click inside the data and press Ctrl+T to make it a table named, for example, Tx. Tables expand automatically and let you write readable formulas like Tx[Amount]. In Google Sheets, use open-ended ranges like Transactions!D2:D so new rows are always included.

Add a category dropdown

A dropdown prevents typos like "Grocery" vs "Groceries" that would break your totals.

  • Excel: select the Category column, then Data > Data Validation > Allow: List, and set the source to =Categories!$A$2:$A$20.
  • Google Sheets: select C2:C, then Data > Data validation > Add rule, choose Dropdown (from a range), and enter Categories!A2:A20.

Importing bank transactions

Most banks let you download a CSV file. In Excel use Data > From Text/CSV; in Google Sheets use File > Import. Banks often export expenses as negative numbers. If yours does, convert them in a helper column with =ABS(D2) or flip the sign with =-D2.

Step 3: Build the Summary tab

In a tab named Summary, put the month you want to view in B1 as the first day of that month (for example, 11/1/2026), with the label "Month" in A1. Then set up a table starting in row 3:

ABCDE
3CategoryBudgetActualRemaining% used

Fill A4 downward with the same categories as the Categories tab.

Budget column

Pull each category's budget from the Categories tab:

=XLOOKUP($A4, Categories!$A$2:$A$20, Categories!$C$2:$C$20, 0)

In older Excel versions, use =IFNA(VLOOKUP($A4, Categories!$A$2:$C$20, 3, FALSE), 0). See XLOOKUP vs VLOOKUP for how these work.

Actual column: SUMIFS by category and month

This is the heart of the budget. It adds up every transaction in the category whose date falls within the month in B1:

=SUMIFS(Transactions!$D:$D, Transactions!$C:$C, $A4, Transactions!$A:$A, ">="&$B$1, Transactions!$A:$A, "<="&EOMONTH($B$1, 0))
  • ">="&$B$1 means "on or after the first of the month."
  • EOMONTH($B$1, 0) returns the last day of that month.

With an Excel table named Tx, the same formula reads more clearly:

=SUMIFS(Tx[Amount], Tx[Category], $A4, Tx[Date], ">="&$B$1, Tx[Date], "<="&EOMONTH($B$1, 0))

Change B1 to another month, and the whole summary updates.

Remaining and percent used

D4: =B4-C4
E4: =IF(B4=0, "", C4/B4)

Format column E as a percentage. Copy B4:E4 down to the last category.

Totals and net cash flow

Below the table, add totals that separate income from expenses. With labels in column A and formulas in column C:

C22 (Total income):    =SUMIFS(C4:C20, A4:A20, "Paycheck")
C23 (Total expenses):  =SUM(C4:C20)-C22
C24 (Net):             =C22-C23

If you have several income categories, add a Type column to the Summary with =XLOOKUP($A4, Categories!$A$2:$A$20, Categories!$B$2:$B$20) and use SUMIFS(C4:C20, F4:F20, "Income") instead.

A useful extra metric is your savings rate: savings divided by income.

C25 (Savings rate):    =XLOOKUP("Savings", A4:A20, C4:C20)/C22

Step 4: Add visual alerts

Use conditional formatting so problems jump out:

  1. Select the Actual cells for your expense categories only — in this example C5:C12, skipping the Paycheck row — and add a custom formula rule =$C5>$B5 with a light red fill. Any category over budget turns red.
  2. Select E5:E12 and apply a color scale from white (0%) to orange (100%) so you can see which categories are nearly used up.

Step 5: Track trends across months

To compare months side by side, build a small grid with categories down column A and month start dates across row 1 (for example, B1 = 1/1/2026, C1 = 2/1/2026, and so on). Then use a SUMIFS that reads its month from the header:

=SUMIFS(Transactions!$D:$D, Transactions!$C:$C, $A2, Transactions!$A:$A, ">="&B$1, Transactions!$A:$A, "<="&EOMONTH(B$1, 0))

Note the mixed references: $A2 locks the category column and B$1 locks the header row, so one formula fills the whole grid. Generate the next month's header with =EDATE(B1, 1).

Add a tiny trend line next to each row with =SPARKLINE(B2:M2) in Google Sheets, or Insert > Sparklines > Line in Excel.

Maintenance tips

  • Enter transactions weekly, not monthly, so the task stays quick.
  • Reconcile your spreadsheet balance against your bank statement once a month.
  • Keep a "Misc" category small; if it grows, split it into real categories.
  • Duplicate the file each January and clear the transactions to start a new year, or keep one file and filter by year.
  • Protect formula cells (Excel: Review > Protect Sheet; Sheets: Data > Protect sheets and ranges) so they are not overwritten accidentally.
