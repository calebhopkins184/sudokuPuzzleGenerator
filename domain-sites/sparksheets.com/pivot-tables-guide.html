Pivot tables in Excel and Google Sheets: a beginner's guide

Updated November 2, 2026 · By the SparkSheets team

A pivot table summarizes a large table of data — totals, counts, or averages — grouped by the categories you choose, without writing formulas. You drag fields into Rows, Columns, Values, and Filters, and the spreadsheet does the math. Pivot tables are the fastest way to answer questions like "What were sales by region by month?"

Step 1: Prepare your data

Pivot tables work best with a clean, "tidy" table. Before you start:

  • One header row with a unique name in every column.
  • One record per row — one sale, one transaction, one ticket.
  • No blank rows or columns inside the data.
  • No merged cells and no subtotal rows mixed in.
  • Consistent data types — real dates in date columns, numbers in number columns (not text that looks like numbers).

Example sales data in A1:E with columns Date, Region, Rep, Product, and Amount.

In Excel, click inside the data and press Ctrl+T (Cmd+T on Mac) to format it as a table. Tables expand automatically when you add rows, so your pivot table will include new data the next time you refresh.

Step 2: Insert the pivot table

In Excel

  1. Click any cell in your data.
  2. Go to Insert > PivotTable.
  3. Confirm the table or range and choose New Worksheet.
  4. Click OK. The PivotTable Fields pane opens on the right.

Not sure where to begin? Insert > Recommended PivotTables suggests layouts based on your data.

In Google Sheets

  1. Select the data range (or click a cell inside it).
  2. Go to Insert > Pivot table.
  3. Choose New sheet and click Create. The Pivot table editor opens.

Google Sheets may also show Suggested pivot tables at the top of the editor.

Step 3: Add fields to the four areas

AreaWhat it doesExample
RowsCreates one row per unique valueRegion
ColumnsCreates one column per unique valueProduct
ValuesThe numbers to summarizeSum of Amount
FiltersLimits which records are includedRep = "Jordan"

In Excel, drag field names into the areas at the bottom of the pane. In Google Sheets, click Add next to each area and choose a field.

With Region in Rows, Product in Columns, and Amount in Values, you get a grid showing total sales for every region and product combination, with grand totals.

Step 4: Change how values are summarized

Numeric fields default to Sum; text fields default to Count (in Google Sheets, COUNTA). To change it:

  • Excel: click the field in Values > Value Field Settings > Summarize Values By and choose Average, Max, Min, Count, and so on.
  • Google Sheets: use the Summarize by dropdown under the value field.

You can add the same field twice — for example, Sum of Amount and Count of Amount — to see both total revenue and number of sales.

Show values as percentages

  • Excel: Value Field Settings > Show Values As > % of Grand Total, % of Column Total, % of Row Total, or Running Total In.
  • Google Sheets: use the Show as dropdown: % of row, % of column, or % of grand total.

Step 5: Group dates by month, quarter, or year

Raw dates create one row per day, which is rarely useful.

  • Excel: recent versions often group dates automatically when you add a date field. Otherwise, right-click a date in the pivot table > Group and select Months, Quarters, and Years. Select both Months and Years if your data spans more than one year, so that January of different years is not combined.
  • Google Sheets: right-click a date in the pivot table > Create pivot date group and choose an option such as Year-Month.

If grouping is unavailable, check for blank cells or dates stored as text in the source column.

Step 6: Sort and filter

  • Sort by clicking the dropdown on a row label (Excel) or using Order and Sort by under Rows (Google Sheets). Sorting regions by total sales, largest first, makes rankings obvious.
  • Filter with the Filters area, or with Top 10 filters in Excel (row label dropdown > Value Filters > Top 10).
  • Slicers (Excel: PivotTable Analyze > Insert Slicer; Google Sheets: Data > Add a slicer) add clickable filter buttons, handy for dashboards.

Step 7: Refresh when data changes

This is the biggest difference between the two apps:

  • Excel pivot tables do not update automatically. After changing source data, click inside the pivot and choose PivotTable Analyze > Refresh, or Data > Refresh All to update every pivot in the workbook. If new rows are outside the original range, use Change Data Source — or use a table so the range grows on its own.
  • Google Sheets pivot tables update automatically when the source data changes, as long as new rows fall inside the selected range. Selecting whole columns, such as A1:E, covers future rows.

Calculated fields

You can add a field calculated from others, such as profit from revenue and cost.

  • Excel: PivotTable Analyze > Fields, Items, & Sets > Calculated Field, then enter a formula like =Revenue - Cost.
  • Google Sheets: in Values, click Add > Calculated field and enter a formula such as =Revenue - Cost using column header names.

Calculated fields operate on the summed values, so ratios like margin are computed from totals rather than averaged row by row.

Pulling pivot results into formulas

In Excel, clicking a pivot table cell while typing a formula inserts a GETPIVOTDATA formula instead of a plain cell reference. It returns a specific value from the pivot and keeps working when the layout changes. Google Sheets supports the same function if you type it yourself:

=GETPIVOTDATA("Amount", $A$3, "Region", "West")

If you prefer normal cell references, you can turn this off in Excel under PivotTable Analyze > Options > Generate GetPivotData.

Pivot table vs formulas

Use a pivot table when...Use formulas (SUMIFS, COUNTIFS) when...
You are exploring data and changing the layout oftenThe layout is fixed, like a monthly report
You need quick totals by several categoriesYou need results to update instantly in Excel without refreshing
The data has thousands of rowsYou want custom formatting cell by cell

For a fixed report, formulas such as SUMIFS are covered in the formula cheat sheet and used throughout the budget spreadsheet tutorial.
