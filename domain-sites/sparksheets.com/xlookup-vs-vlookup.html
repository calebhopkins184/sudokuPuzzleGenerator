XLOOKUP vs VLOOKUP: how to look up data in Excel and Google Sheets

Updated November 2, 2026 · By the SparkSheets team

VLOOKUP searches the first column of a range and returns a value from a column to its right. XLOOKUP searches any column and returns from any other column, defaults to an exact match, and lets you specify what to show when nothing is found. If your version supports XLOOKUP, it is usually the better choice.

The sample data

The examples use a product list in A1:D6:

ABCD
1SKUProductCategoryPrice
2P-100NotebookPaper4.50
3P-205Gel penWriting1.75
4P-310StaplerDesk12.00
5P-415Sticky notesPaper3.25
6P-520Desk lampDesk29.99

Cell G2 holds the SKU you want to look up, such as P-310.

VLOOKUP syntax

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])
  • lookup_value — what to find (G2).
  • table_array — the range to search; the lookup column must be the first column.
  • col_index_num — which column of the range to return, counting from 1.
  • range_lookup — FALSE for exact match, TRUE (the default) for approximate match.

To return the price for the SKU in G2:

=VLOOKUP(G2, $A$2:$D$6, 4, FALSE)

Result: 12.00.

The most common VLOOKUP mistake is leaving off the last argument. The default is approximate match, which can silently return the wrong row if your data is not sorted. Always type FALSE (or 0) for exact matches. Google Sheets works the same way: its last argument, is_sorted, also defaults to TRUE.

VLOOKUP's limitations

  • It can only return columns to the right of the lookup column.
  • The column number is hard-coded, so inserting a column inside the range can break it.
  • It returns #N/A when there is no match, which you must wrap in IFERROR or IFNA.

XLOOKUP syntax

=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])
  • lookup_array — the single column (or row) to search.
  • return_array — the column (or columns) to return.
  • if_not_found — what to show if there is no match.
  • match_mode — 0 exact (default), -1 exact or next smaller, 1 exact or next larger, 2 wildcard.
  • search_mode — 1 first to last (default), -1 last to first, plus binary search options 2 and -2 for sorted data.

The same price lookup:

=XLOOKUP(G2, $A$2:$A$6, $D$2:$D$6, "Not found")

XLOOKUP is available in Excel for Microsoft 365, Excel 2021 and later, Excel for the web, and Google Sheets. It is not available in Excel 2019 or earlier.

Useful XLOOKUP patterns

Look up to the left

Find the SKU for a product name typed in G3:

=XLOOKUP(G3, $B$2:$B$6, $A$2:$A$6, "No such product")

Return several columns at once

Return the product, category, and price for the SKU in G2. The result spills into three adjacent cells:

=XLOOKUP(G2, $A$2:$A$6, $B$2:$D$6)

Approximate match for tiers

Approximate matching is ideal for tax brackets, commission rates, or grades. With thresholds in J2:J5 (0, 60, 75, 90) and letter grades in K2:K5 (F, C, B, A):

=XLOOKUP(H2, $J$2:$J$5, $K$2:$K$5, , -1)

Match mode -1 returns the grade for the largest threshold that is less than or equal to the score. A score of 82 returns B. The VLOOKUP equivalent requires the thresholds sorted ascending:

=VLOOKUP(H2, $J$2:$K$5, 2, TRUE)

Find the most recent entry

To return the latest price recorded for a SKU in a log where new rows are added at the bottom, search from last to first:

=XLOOKUP(G2, Log!A:A, Log!C:C, "None", 0, -1)

Two-way lookup

Nest one XLOOKUP inside another to match both a row and a column header. With regions in A2:A10, months in B1:M1, and values in B2:M10:

=XLOOKUP(P1, $A$2:$A$10, XLOOKUP(P2, $B$1:$M$1, $B$2:$M$10))

INDEX/MATCH: the classic alternative

Before XLOOKUP, INDEX with MATCH was the standard flexible lookup, and it still works in every version of Excel and in Google Sheets.

=INDEX($D$2:$D$6, MATCH(G2, $A$2:$A$6, 0))

MATCH finds the position of G2 in column A; INDEX returns the value at that position in column D. The 0 in MATCH means exact match — its default, 1, is approximate.

Fixing common lookup errors

ProblemLikely causeFix
#N/A when the value clearly existsExtra spaces, or numbers stored as textUse TRIM(); convert text to numbers with VALUE() or by multiplying by 1
Wrong result, no errorVLOOKUP approximate match on unsorted dataAdd FALSE as the last argument
#REF!VLOOKUP column number larger than the rangeFix col_index_num or switch to XLOOKUP
Results shift after copyingRelative referencesLock ranges with $, as in $A$2:$A$6
#SPILL! in ExcelCells where results would spill are not emptyClear the cells below or to the right
#NAME?XLOOKUP not supported in your Excel versionUse INDEX/MATCH or VLOOKUP

To hide errors only when a match is missing, wrap older formulas in IFNA:

=IFNA(VLOOKUP(G2, $A$2:$D$6, 4, FALSE), "Not found")

IFNA is safer than IFERROR because it does not mask other mistakes, such as a typo that causes #REF!.
